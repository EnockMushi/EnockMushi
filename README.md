## About Me

I'm a **Graphics & UI/UX Designer and Full-Stack Developer** based in Dar es Salaam, Tanzania. I design interfaces that look considered and then build them so they actually work — that combination is the core of what I do.

Most of my work lives at the intersection of **visual design and working software**. That means brand identity and interface design, yes, but also the PHP and MySQL behind them, the responsive layouts, and the design systems that keep a dozen screens looking like one product.

I work with **Lorris Designs**, where I take on design and development for clients who need both.

### Design Principles I Work By

- **Design system first.** Tokens before pages. Every colour, radius and spacing step as a variable — so a rebrand is one file, not a find-and-replace.
- **Accessibility is not a phase.** Skip links, ARIA state, focus visibility, WCAG AA contrast. Checked in markup, not bolted on.
- **Performance is a design decision.** `transform` and `opacity` only. Self-hosted assets. No framework where none is needed.
- **The build must match the design.** If I hand over a mockup that doesn't survive real data and real edge cases, I've only done half the job.
